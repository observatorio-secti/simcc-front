# Fontes

A plataforma usa apenas **Lexend** (pesos variáveis 100–900), carregada do Google Fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Lexend:wght@100..900&display=swap" rel="stylesheet">
```

`tokens/simcc.css` já importa a fonte. Para uso offline, coloque aqui os arquivos `Lexend[wght].woff2` (licença SIL OFL) e troque o `@import` por um `@font-face` local.
